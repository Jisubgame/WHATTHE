발전기 4대를 켜면 보안실 코드 4자리가 나온다.
빨간 열쇠로 동쪽 문 열기 → 영안실에서 퓨즈 → 보안실 앞 퓨즈 박스 → 키패드에 코드 → 카드키 → 비상구.

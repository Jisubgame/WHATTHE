# SM1IILE 로블록스 이식 명세서 (원본 웹판 수치 그대로)

**규칙: 짐작하지 말고 이 숫자대로. 결과는 `reference/` 스크린샷과 같은 위치·각도로 찍어서 나란히 비교한다.**
단위: 원본은 미터. **studs = m × 3.5.** 좌표축은 Config.cellToWorld와 같다(칸 (r,c) 중심 = ((c−16)×4, (r−16)×4) m).

## 작업 순서 (이 순서를 지킬 것)
1. 분위기(어둠·안개·손전등) → `reference/02~04` 와 똑같아질 때까지
2. 조작(걷기·달리기·스테미나·앉기) → `11_crouch_view`
3. 맵 재질·조명·소품 배치 → `placement.json`, `00_map_placement`, `01, 05~07`
4. 괴물(모델·콧노래·AI) → `13`
5. 숨기 → `15`
6. 퍼즐(셔터·키패드·서랍·발전기·비상구) → `08, 09, 12, 14`
7. 목숨·HUD·메뉴

## 1. 분위기 (가장 중요: 지금 너무 밝음)
원본은 손전등 원 밖이 거의 새까맣다. 천장 조명 바로 밑만 희미하게 보인다.
- 하늘/환경광 없음. 실내 전체가 막혀 있음(천장 있음).
- 환경광: Ambient 색 #6f7f9c 세기 0.3 + 반구광 위 #8494b4 / 아래 #1c1610 세기 0.2. **손전등을 끄면 0.045 / 0.03까지 내려가고, 4초에 걸쳐 눈이 적응하며 0.2 / 0.13까지 오른다.**
- 안개: 지수 안개 색 **#030405**, 밀도 **0.06 /m**. 약 10m 앞이 거의 검게 묻힘.
- 노출(tone mapping) ACES, 노출 1.35.
- **로블록스 권장값(출발점):** Lighting.Technology = Future, Brightness = 0, Ambient = (12,13,16), OutdoorAmbient = (0,0,0), EnvironmentDiffuseScale = 0, EnvironmentSpecularScale = 0, GlobalShadows = true, ClockTime = 0. Atmosphere: Density 0.45, Color/Decay = (3,4,5), Haze 0, Glare 0. 그다음 `02~04` 스크린샷과 비교해 Density·Ambient만 조절.

### 손전등 (SpotLight, 플레이어 카메라에 붙임)
- 색 #ffeccc, 세기 45(원본 단위) → 로블록스 Brightness 3~5에서 맞춤.
- **원뿔 반각 0.47 rad = 27° → 로블록스 SpotLight.Angle = 54.**
- 가장자리 흐림(penumbra) 0.55. 사거리 32m → 로블록스 Range 최대 60 studs 사용.
- 그림자 켬. 카메라 오른쪽 0.18m, 아래 0.2m에서 나가고, 시선을 부드럽게(초당 14배 보간) 따라감.
- 숨어 있을 때도 켤 수 있음(밝기 18로 낮춤). 괴물은 숨은 곳 불빛에 반응 안 함.
- 플레이어 주변 약한 빛(PointLight) #a8b4c8, 세기 2.4, 범위 8m(28 studs). 손전등 끄면 범위 3.8→7.8m, 세기 1.3→3.5로 눈 적응.

### 천장 조명
- 배치 규칙: 바닥 칸 중 **(r×7 + c×13) % 5 == 0** 인 칸. 종류 h=(r×31 + c×17) % 10: **h<2 켜짐, h<4 깜빡임, 나머지 꺼짐.** 로비는 한 칸 걸러 전부 켜짐. 환기구 안엔 없음. 위치 목록: `placement.json`의 `lamps`.
- 빛: PointLight #d6e6ff, 범위 9m(31.5 studs), 켜짐 세기 5.2, 깜빡임은 불규칙하게 0~1.4 오감.
- **실제 광원은 플레이어와 가까운 4개만 켠다**(나머지는 빛나는 형광등 메시만). 로블록스도 전부 켜면 밝아지고 느려짐.
- 꺼진 조명은 발전기를 켜면 반경 12m 안이 켜지고, 4대 다 켜면 전부 켜짐(0.8).
- 출구 위 빨간 PointLight #ff2020, 세기 4, 범위 9m.

### 재질
- 벽: `assets/tex/wall.jpg` (흰 타일 위, 아래쪽 초록 페인트 벗겨짐). 높이 0.428×벽높이에 가로 철제 난간.
- 바닥: `assets/tex/floor.jpg` (흑백 체크, 얼룩). 천장: `assets/tex/ceil.jpg` (누런 얼룩 타일).
- 벽 높이 3.4m(12 studs), 칸 4m(14 studs). 방 벽 두께 0.24m, 방 문 폭 1.25m.

## 2. 플레이어
- 눈높이 **1.62m**, 앉으면 **1.05m**(카메라 높이를 부드럽게 9배속 보간).
- 속도(m/s): 걷기 **3.3**(11.5 studs), 달리기 **6.1**(21.4), 앉아서 **1.6**(5.6), 지쳤을 때 **2.5**(8.75). 점프 없음.
- 스테미나 100: 달리면 초당 **−21**, 움직이며 쉴 때 **+11**, 서 있을 때 **+17**, 숨어 있을 때 +20. 0이 되면 지침 → **35 넘을 때까지 못 달림.**
- 앉은 채 달리기 누르면 자동으로 일어섬. 환기구 안에서는 강제로 앉고 못 일어섬.
- 화면 아래 스테미나 바: 99.5 미만일 때만 보임. 얇은 막대, 지치면 빨갛게 깜빡임.
- 시야각(FOV) 72°, 달릴 때 80°.
- 상호작용: **2.4m 이내 + 화면 가운데가 그 물건을 보고 있을 때만**(발전기·비상구 2.8m). 보고 있는 물건은 흰 외곽선이 은은하게 빛남.

## 3. 괴물
- 키 = 플레이어의 약 1.3배. 웃는 창백한 거인. 모델 `assets/monster.glb`(걷기 `Limping_Walk_3_inplace`, 두리번 `Look_Around_Dumbfounded`, 달리기 `Lean_Forward_Sprint_inplace`).
- **발소리 없음. `assets/sfx/hum.wav`(28초 루프 콧노래)를 몸에 붙인 3D 소리로.** 36m(126 studs)부터 들리고 가까울수록 큼(거리비^1.35). 벽에 가려지면 저역통과로 먹먹하게(650Hz~, 보이면 5200Hz).
- 속도(m/s): 순찰 **2.7**, 조사 3.0, 숨은 곳 찾기 3.6, **추격 5.9**(플레이어 달리기와 거의 같음). 쉬움 ×0.85, 어려움 ×1.15(추격은 쉬움 ×0.93, 어려움 ×1.02).
- 시야: 플레이어 손전등 켜짐 **20m**, 꺼짐 **9m**, 앉으면 ×0.65. 정면 ±66°(1.15 rad), 단 4.2m 안(앉고 불 끄면 2.2m)은 방향 상관없이 봄. 벽 너머는 못 봄. 난이도 배율 쉬움 0.8 / 보통 1 / 어려움 1.2.
- 청각: 플레이어 소음 반경 **달리기 15m, 걷기 6.5m(느리게 3m), 앉아서 1.2m**. 난이도 배율 쉬움 0.95 / 보통 1.25 / 어려움 1.6. 들리면 그 자리로 조사하러 옴.
- 순찰: 다음 지점을 **50%는 플레이어와 가장 가까운 순찰 지점 4곳 중 하나**(자기 근처 3칸 이내 제외), 50%는 무작위. 순간이동 연출 없음.
- 추격: 보이면 쫓고, 놓치면 마지막 위치로 가서 5초 뒤 두리번(3.5초) → 순찰.
- **잡힘 거리 1.3m(4.5 studs).** 로비·환기구 안에서는 못 보고 못 잡음, 들어오지도 않음.
- 멀티 보정(로블록스 전용): 인원 1명당 순찰 +6%, 시야 +8%, 추격 +3%.

## 4. 숨기
- 사물함(`assets/locker.glb`), 침대 밑, 책상 밑. 들어가고 나오는 짧은 카메라 애니메이션.
- 사물함 안: 실제 내부가 보이고 문 틈(가로 살)으로 밖이 보임. 고개 돌리기 ±0.5 rad.
- 괴물이 숨는 걸 보면 찾아옴. **처음 3번(어려움 2번)은 문 앞까지 와서 들여다보고 돌아감**, 그 뒤엔 끌어냄.

## 5. 목숨
- 3개. 잡히면 점프스케어 → 검은 화면에 흰 세로 막대 3개 → 잃은 막대가 빨갛게 번쩍·흔들리다 아래로 꺼짐 → 로비에서 다시 시작(진행 유지). 게임 시작 때도 검은 화면에 막대 표시.
- 안 쓴 빨간 열쇠/퓨즈/카드키는 무작위 막다른 곳으로 흩어짐(알림 없음). 빨간 열쇠는 셔터 앞쪽(서쪽)에만.

## 6. 맵·소품
- 격자: `Config.lua` GRID. 방 7개는 격자상 1(벽)이지만 **안이 비어 있는 방**이다(문으로 들어감): `placement.json`의 `rooms`(행, 열 범위, 문 위치, 문 방향, 소품 목록).
- **소품 좌표는 `placement.json` 그대로 쓴다.** x,z는 m(×3.5), rotY는 라디안(모델 정면 +Z 기준).
  - `rooms[].items`: 방 소품. `corridorProps`: 복도 소품. `lockers`: 사물함. `hideUnder`: 침대/책상 밑 숨는 곳. `doors`: 방 문. `lamps`: 조명.
- 소품 종류 → 모델 파일, 목표 높이(m):
  bed→bed.glb 1.1 · wheelchair 1.0 · ivStand→iv.glb 1.9 · cart 1.0 · cabinet 1.8 · desk 1.25 · opTable→op_table.glb 1.15 · shelf 2.0 · morgueWall→morgue_cab.glb 2.1 · gurneyBag→gurney.glb 1.1 · sofa 0.9 · vending 1.95 · surgLamp→surg_lamp.glb 1.2(천장에 매달림) · officeChair→office_chair.glb 1.05 · lowTable→coffee_table.glb 0.45 · tray 1.0 · boxes 1.2 · curtain 2.45 · metalChair→metal_chair.glb 0.85 · stretcher 1.0 · filing 1.35 · mop 0.9 · trash 0.65 · reception 1.15 · extinguisher 0.6 · clock 0.45 · phone 0.45. (bed, opTable, gurneyBag, stretcher는 모델을 90° 돌려서 긴 쪽이 X축)
- 방 목록: 보안실 SEC(잠김, 키패드), 간호사실 NS, 수술실 OR-2, 404 병실, 비품 창고 B-09, 영안실 B-13(보관함 2개 × 서랍 12칸), 직원 휴게실 B-07.
- 빨간 셔터: 칸 (13,21). 보안실 문 (5,18), 퓨즈 박스는 문 왼쪽 1.35m, 키패드는 오른쪽 1.25m, 높이 ~1.3m. 비상구: (32,29), 문이 북쪽(-Z)을 봄.
- 발전기 후보: 서쪽 (5,3)(7,5)(9,3)(11,19)(13,9)(15,9)(15,13)(17,3)(19,9)(19,13)(21,7)(21,20)(25,9)(25,11) / 동쪽 (3,29)(5,22)(7,22)(19,22)(25,22)(27,22)(29,22)(29,25). 매판 서2+동2, 서로 6칸 이상 떨어짐.
- 빨간 열쇠 후보: (7,9)(13,7)(9,5). 쪽지 2장(코드 앞2/뒤2): 아무 방 또는 아무 복도(환기구 제외) 무작위.
- 카드키: 보안실 책상 위에 평범하게 눕혀 놓음(받침대·빛 없음).

## 7. 글귀 원칙
짧고 불친절하게. 사람이 쓴 1인칭. "그것은 ~했다" 같은 내레이션 금지. 예: "합선", "발전기 2/4", "열쇠가 없다", "비어 있다".

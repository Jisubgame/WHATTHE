# SM1IILE → Roblox 이식 인계 문서

> **먼저 `roblox/SPEC.md`(원본 수치 명세)와 `roblox/reference/`(원본 스크린샷·placement.json)를 볼 것. 짐작하지 말고 그 숫자와 좌표대로 만들고, 같은 장면을 찍어 비교할 것.**

웹판(이 저장소의 index.html / js/main.js)을 로블록스로 옮기는 작업. 사용자는 한국어로 대화하고, 최소한의 수정을 선호한다(요청 범위만, 리팩터링 금지). 로블록스 스튜디오는 처음이라 직접 조작은 Claude가 컴퓨터 사용으로 대신한다.

## 게임 요약 (웹판 기준, 현재 상태)
- 1인칭 3D 잠입 공포. 폐병동 B2 4병동, 33×33 격자 맵(Config.lua의 GRID와 같음).
- 괴물: 키 큰 창백한 존재, 기괴하게 웃는 얼굴. 발소리 대신 **뒤틀린 콧노래**(28초 루프, 거리 따라 커지고 벽 너머면 먹먹함). 웹판 소리 파일: assets/sfx/hum.wav.
- 괴물 AI: 순찰만 함(순간이동 연출 없음). 다음 순찰 지점을 50% 확률로 플레이어와 가까운 지점 4곳 중 하나로, 나머지는 무작위로 고른다. 보이면 추격(플레이어 달리기와 거의 같은 속도), 놓치면 5초 뒤 두리번 → 순찰. 소리(달리기 > 걷기 > 숙이기)와 손전등 불빛으로 찾아옴.
- 안전지대: 남쪽 로비(불 켜짐, 괴물 못 들어옴), 서쪽 환기구(기어서만, 괴물 못 따라옴).
- 숨기: 사물함, 침대 밑, 책상 밑. 처음 3번(어려움 2번)은 봐주고 그 뒤론 끌어냄. 숨어서도 손전등 사용 가능(괴물은 반응 안 함).
- 탈출 순서: 발전기 4대(게이지 미니게임, 전력용) / 빨간 열쇠(서쪽 미로 막다른 곳) → 빨간 셔터(13,21) 열쇠 꽂기 → 동쪽 병동 / 영안실 서랍 12칸 중 하나에 퓨즈 → 보안실 앞 퓨즈 박스 → 키패드 전원 / 코드 4자리는 쪽지 2장(앞 2자리, 뒤 2자리, 위치 완전 랜덤) → 키패드 입력 → 보안실 책상 위 카드키(평범하게 놓여 있음) → 남동쪽 끝 비상구(32,29). 발전기 4대 + 카드키 둘 다 있어야 열림.
- 목숨 3개: 잡히면 검은 화면에 흰 막대 3개, 잃은 막대가 빨갛게 번쩍이며 꺼짐. 로비에서 다시 시작, 진행은 유지. 들고 있던 빨간 열쇠/퓨즈/카드키는 무작위 막다른 곳으로 흩어짐(알림 없음). 빨간 열쇠는 셔터 앞쪽에만 떨어짐.
- 상호작용: 2.4m 이내 + 바라보고 있을 때만. 바라보면 흰 외곽선이 은은하게 빛남.
- 글귀 원칙: 짧고 불친절하게, 사람이 쓴 1인칭. "그것은 ~" 같은 내레이션 금지.
- 이름: SM1IILE. 타이틀 글꼴 Bodoni Moda Black, UI는 Hahmlet.

## 로블록스 결정 사항
- **멀티플레이**(2~4명 협동). 인원이 늘면 더 어렵게: 1명당 순찰 +6%, 시야 +8%, 추격 +3%.
- 단위: 1칸 = 14 studs(≈4m), 벽 높이 12 studs. 플레이어 걷기 12, 달리기 20(예정). 괴물 순찰 9.5, 추격 20.5.
- 소리는 파일로 업로드해야 함(웹판은 대부분 코드 생성). 마이크 기능은 나중에.

## 진행 단계
1. ✅ 뼈대 스크립트 작성 (아직 스튜디오에 넣고 테스트 안 함)
   - ReplicatedStorage/Config (ModuleScript) ← roblox/Config.lua
   - ServerScriptService/MapBuilder (Script) ← roblox/MapBuilder.server.lua
   - ServerScriptService/Monster (Script) ← roblox/Monster.server.lua
   - 새 Baseplate 템플릿에서 기본 Baseplate 삭제 후 넣고 F5로 테스트.
2. 괴물 모델(assets/monster.glb) 가져오기 + 애니메이션 + 콧노래 3D 사운드
3. 잠입: 달리기/숙이기, 소리 범위, 손전등 시야, 숨기
4. 탈출 순서 퍼즐 전부
5. 목숨, HUD, 메뉴
6. 배지/수익화

## 다음에 할 일
스튜디오에 1단계 스크립트 3개를 넣고 플레이 테스트 → 출력(Output) 에러 확인 → 괴물이 순찰/추격/로비 회피하는지 확인.

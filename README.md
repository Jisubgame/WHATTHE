# WHATTHE

폐쇄된 4병동에서 탈출하는 1인칭 3D 스텔스 공포 게임. PC와 모바일 브라우저에서 돌아갑니다.

33×33 병동: 서쪽 미로, 가운데 복도, 빨간 문 너머 동쪽 병동, 남쪽 로비(안전지대)로 나뉩니다.

탈출 순서:
1. **발전기 4대** (서쪽 미로 2대, 동쪽 병동 2대) — 켤 때마다 계기판에 보안실 코드 한 자리(I~IV)가 뜬다.
2. **빨간 열쇠** — 서쪽 미로 막다른 길 중 한 곳(매판 바뀜) → 가운데 복도 끝의 **빨간 문**을 연다. 그것도 이제 동쪽으로 들어온다.
3. **퓨즈** — 동쪽 영안실 시신 보관함 서랍 6개 중 하나. 서랍 여는 소리는 들린다.
4. **퓨즈 박스** — 보안실 문 옆. 꽂으면 키패드에 불이 들어온다.
5. **키패드** — 아는 코드를 입력(틀리면 시끄럽다). 입력하는 동안에도 게임은 멈추지 않는다.
6. 보안실 책상의 **카드키** → 북쪽 **비상구**.

- 남쪽 로비는 불이 켜져 있어 그것이 들어오지 못한다.
- 서쪽 **환기구**는 기어서만 지나갈 수 있고, 그것은 따라오지 못한다.
- 손전등은 배터리 없이 계속 쓸 수 있다. 대신 켜 두면 멀리서도 보인다.

## 그것

- **소리를 듣는다** — 뛰면 15m, 걸으면 6m, 숙이면 1m 안에서 들린다. 발전기 크랭크 소리도, 시동 실패는 더 크게 들린다.
- **발전기 시동** — 다이얼 바늘이 엔진처럼 들쭉날쭉 돌고, 2단계부터는 초록 구간도 반대로 돈다. 괴물이 오면 언제든 물러날 수 있고(PC는 WASD, 모바일은 물러나기 버튼·조이스틱), 돌려둔 단계는 유지된다.
- **불빛을 본다** — 손전등을 켜면 20m 밖에서도 보이고, 끄면 9m까지만 보인다.
- **숨기** — 사물함 안, 404 병실 침대 밑, 간호사실 책상 밑에 숨을 수 있다. 사물함 환기구 틈으로 밖이 보인다.
- **봐주는 건 처음 몇 번뿐** — 숨는 걸 들켜도 처음 3번(어려움 2번)은 문 앞까지 와서 숨소리만 듣고 돌아간다. 그 다음부턴 끌려 나온다.

## 방

복도 사이에 들어갈 수 있는 방이 7개 있습니다. 문은 직접 열고 닫을 수 있어요.

| 방 | 안에 있는 것 |
|---|---|
| 보안실 | 잠김. 키패드 코드로 연다 — 카드키가 있다 |
| 간호사실 | 책상, 모니터, 사물함 |
| 수술실 | 수술대, 무영등, 핏자국 |
| 404 병실 | 침대 3개, 커튼, 벽의 웃음 |
| 비품 창고 | 선반, 상자, 사물함 |
| 영안실 | 시신 보관함 서랍 — 퓨즈가 하나에 들어 있음. 전력 복구 전엔 불이 꺼져 있음 |
| 직원 휴게실 | 소파, 자판기, 사물함 |

- 방 곳곳에 기록이 숨겨져 있다.
- 문을 닫으면 그것의 시야를 가린다. 하지만 문 여닫는 소리는 들린다.
- 그것도 문을 열고 들어온다. 삐걱 소리가 나면 근처에 있다는 뜻.

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 화면 왼쪽 끌기 |
| 시점 | 마우스 (클릭하면 고정) | 화면 오른쪽 끌기 |
| 달리기 | Shift | 달리기 버튼 (켜기/끄기) |
| 숙이기 | C | 숙이기 버튼 |
| 손전등 | F | 손전등 버튼 (오른쪽 아래) |
| 키패드 | 숫자키 · Backspace · Enter · Esc | 화면 버튼 |
| 상호작용 | E / 클릭 | 화면 탭 / 사용 버튼 |
| 일시정지 | Esc | ⏸ 버튼 |

난이도는 쉬움 · 보통 · 어려움. 난이도별 최고 기록이 저장됩니다.

## 실행

`index.html`이 `js/`, `css/`, `assets/`를 불러오기 때문에 웹 서버로 열어야 합니다
(파일을 더블클릭해서 열면 모델이 안 뜹니다).

- GitHub Pages: Settings → Pages → Branch `main` / `(root)`
- 로컬: `python3 -m http.server` 후 `http://localhost:8000`

## 구성

- `index.html` — 화면 구조 (메뉴, HUD, 모달)
- `css/style.css` — UI 스타일
- `js/main.js` — 게임 전체 (three.js 0.160, CDN)
- `assets/monster.glb` — 괴물 (걷기·수색·질주·돌진 애니메이션)
- `assets/generator.glb`, `assets/locker.glb` — 발전기, 사물함
- `assets/jumpscare.jpg` — 점프스케어 이미지

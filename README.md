# WHATTHE

폐쇄된 4병동에서 탈출하는 1인칭 3D 스텔스 공포 게임. PC와 모바일 브라우저에서 돌아갑니다.

발전기 4대를 게이지 미니게임으로 가동하고, 카드키를 찾아 비상구로 나가세요.
발전기와 카드키, 아이템 위치는 판마다 바뀝니다.

## 그것

- **소리를 듣는다** — 뛰면 15m, 걸으면 6m, 숙이면 1m 안에서 들린다. 발전기 크랭크 소리도, 시동 실패는 더 크게 들린다.
- **발전기 시동** — 다이얼 바늘이 엔진처럼 들쭉날쭉 돌고, 2단계부터는 초록 구간도 반대로 돈다. 도중에 자리를 비우면 엔진이 꺼져 처음부터.
- **불빛을 본다** — 손전등을 켜면 20m 밖에서도 보이고, 끄면 9m까지만 보인다.
- **병 깨지는 소리를 쫓아간다** — 빈 병을 던져서 다른 곳으로 유인할 수 있다.
- **숨기** — 사물함 안, 404 병실 침대 밑, 간호사실 책상 밑에 숨을 수 있다. 사물함 환기구 틈으로 밖이 보인다.
- **봐주는 건 처음 몇 번뿐** — 숨는 걸 들켜도 처음 3번(어려움 2번)은 문 앞까지 와서 숨소리만 듣고 돌아간다. 그 다음부턴 끌려 나온다.

## 방

복도 사이에 들어갈 수 있는 방이 6개 있습니다. 문은 직접 열고 닫을 수 있어요.

| 방 | 안에 있는 것 |
|---|---|
| 간호사실 | 책상, 모니터, 사물함 — 카드키가 있을 수 있음 |
| 수술실 | 수술대, 무영등, 핏자국 |
| 404 병실 | 침대 3개, 커튼, 벽의 웃음 |
| 비품 창고 | 선반, 상자, 사물함 — 카드키가 있을 수 있음 |
| 영안실 | 시신 보관함, 시신 가방. 전력 복구 전엔 불이 꺼져 있음 |
| 직원 휴게실 | 소파, 자판기, 사물함 — 카드키가 있을 수 있음 |

- 방마다 배터리·병·기록 중 하나가 숨겨져 있다.
- 문을 닫으면 그것의 시야를 가린다. 하지만 문 여닫는 소리는 들린다.
- 그것도 문을 열고 들어온다. 삐걱 소리가 나면 근처에 있다는 뜻.

## 아이템

| | |
|---|---|
| 배터리 | 손전등 +45%. 켜 두면 계속 닳는다 |
| 빈 병 | 최대 3개. 던지면 깨지는 소리로 유인 |
| 기록 (5장) | 병동에서 무슨 일이 있었는지, 그리고 살아남는 힌트 |

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 화면 왼쪽 끌기 |
| 시점 | 마우스 (클릭하면 고정) | 화면 오른쪽 끌기 |
| 달리기 | Shift | 달리기 버튼 (켜기/끄기) |
| 숙이기 | C | 숙이기 버튼 |
| 손전등 | F | 손전등 버튼 (오른쪽 아래) |
| 병 던지기 | Q / 우클릭 | 던지기 버튼 |
| 상호작용 | E / 클릭 | 화면 탭 / 사용 버튼 |
| 일시정지 | Esc | ⏸ 버튼 |

난이도는 쉬움 · 보통 · 어려움. 난이도별 최고 기록이 저장됩니다.

## 실행

`index.html`이 `js/`, `css/`, `assets/`를 불러오기 때문에 웹 서버로 열어야 합니다
(파일을 더블클릭해서 열면 모델이 안 뜹니다).

- GitHub Pages: Settings → Pages → Branch `main` / `(root)`
- 로컬: `python3 -m http.server` 후 `http://localhost:8000`

## 구성

- `index.html` — 화면 구조 (메뉴, HUD, 모달)
- `css/style.css` — UI 스타일
- `js/main.js` — 게임 전체 (three.js 0.160, CDN)
- `assets/monster.glb` — 괴물 (걷기·수색·질주·돌진 애니메이션)
- `assets/generator.glb`, `assets/locker.glb` — 발전기, 사물함
- `assets/jumpscare.jpg` — 점프스케어 이미지
